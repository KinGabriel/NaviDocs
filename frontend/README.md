
## Frontend Setup

1. Navigate to the frontend directory:
   ```sh
   cd frontend
   ```

2. Install dependencies:
   ```sh
   npm install
   ```

3. Install additional packages:
   ```sh
   npm install react-router-dom@7
   npm install tailwindcss @tailwindcss/vite
   ```


## Run the react frontend
1. Navigate to the frontend directory:
   ```sh
   cd frontend
   ```

2. Run:
   ```sh
   npm run dev
   ```
